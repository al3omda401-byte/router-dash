# Router Dashboard — Cloud + Local Agent

الواجهة بتشتغل على Render، والراوتر بيتحكم فيه وكيل محلي على جهاز المالك
(لأن الراوتر على شبكة البيت ومش متاح من الإنترنت).

## السحابة (Render)
- Start command: `python cloud_app.py`
- Health check: `/healthz`
- متغيرات البيئة:
  - `AGENT_KEY` — مفتاح سري بين السحابة والوكيل (إجباري)
  - `DASH_PASS` — باسورد اللوحة (Basic auth) — إجباري للرابط العام
  - `DASH_USER` — افتراضي `admin`

## الوكيل المحلي (على جهاز المالك)
```
set CLOUD_URL=https://<service>.onrender.com
set AGENT_KEY=<نفس المفتاح>
python router_agent.py
```
- بيقرا بيانات الراوتر من `config.ini` (جنب الملفات) — الباسورد **مايتسربش للسحابة**.
- بيسحب الأوامر كل ~1.2 ثانية، وبيرفع الحالة كل ~8 ثواني والسرعة كل ثانيتين.
- ممكن يشتغل تلقائي من Task Scheduler عند تسجيل الدخول.

## ملاحظات
- الرابط العام لازم يبقى عليه `DASH_PASS`، لأن أي حد يعرفه يقدر يشوف الأجهزة.
- أي أمر (حظر/ريستارت/دخول) بيتنفّذ على جهازك، والسحابة مجرد ناقل.
